Pin Connections Summary:
═══════════════════════════════════════════════════════════════

DHT22 Sensor:
  • VCC  (Power)    → ESP32 3.3V pin
  • DATA (Signal)   → ESP32 GPIO 4
  • GND  (Ground)   → ESP32 GND pin

LED Circuit:
  • Anode (+) longer leg  → 220Ω Resistor → ESP32 GPIO 18
  • Cathode (-) shorter   → ESP32 GND pin


Notes:
──────
1. DHT22 can use 3.3V or 5V (3.3V works fine)
2. 220Ω resistor protects LED from overcurrent
3. LED polarity matters: Longer leg = Anode (+)
4. All grounds must be connected together (common ground)
5. Optional: Add 10kΩ pull-up resistor between DHT22 DATA and VCC
   if you experience unreliable readings
