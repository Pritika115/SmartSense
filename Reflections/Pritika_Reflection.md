# Pritika – Reflection (Check-In 2)

In the SmartSense project, my role focuses on Python UI development, documentation, and testing. For Check-In 2, I contributed to preparing the system to read data from the Arduino Uno and DHT22 sensor through MQTT. I learned how the DHT22 sensor works, why it is more accurate than the DHT11, and how the Arduino publishes data that can be consumed by a Python subscriber.

I also began shaping the Python console UI, which will subscribe to MQTT topics, print real-time temperature and humidity values, and later store data for the REST API. During testing, I helped identify common issues such as serial port permission errors, MQTT broker connection failures, and incorrect COM port selection.

Working on documentation helped me understand the system architecture better, including how the LED output will be controlled using REST API-based commands. In the upcoming phase, I will finalize the UI features, ensure proper data logging, and support integration testing for the complete end-to-end pipeline.
